# 🎮 Simon Says Game

A fun and interactive memory game built using **HTML, CSS, and JavaScript**. Test your memory by remembering and repeating increasingly challenging color sequences.

## ✨ Features

- 🎨 **Interactive UI** — Colorful buttons with visual feedback.
- 🧠 **Memory Challenge** — Memorize and repeat the sequence in the correct order.
- 📈 **Increasing Difficulty** — The sequence grows with each successful round.
- 🏆 **High Score Tracking** — Keep track of your highest score and challenge yourself to beat it.
- ⚡ **Instant Feedback** — Visual cues for button presses and game progress.
- 🌐 **Browser-Based** — Play directly in your web browser.

## 🛠️ Tech Stack

- **HTML5** — Structures the game.
- **CSS3** — Handles styling, layout, and animations.
- **JavaScript** — Implements game logic, sequence generation, user interactions, and high-score functionality.

## 🎯 How to Play

1. Start the game according to the instructions displayed on the screen.
2. Watch the color sequence carefully.
3. Repeat the sequence by clicking the colored buttons in the same order.
4. Each successful round adds another step to the sequence.
5. Make a mistake, and the game ends. Try again to beat your high score!

## 🚀 Getting Started

### Prerequisites

A modern web browser is all you need.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohitdev75/simon-says-game.git
   ```

2. Navigate to the project folder:

   ```bash
   cd simon-says-game
   ```

3. Open `SimonSays.html` in your browser, or use the Live Server extension in VS Code.
